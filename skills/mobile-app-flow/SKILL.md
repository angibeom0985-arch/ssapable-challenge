# 모바일/웹 앱 동선 분석 자동화 스킬 (mobile-sns-flow-analyzer-v1)

## 표준 동선
1. 앱/모바일 웹 진입 및 로그인 세션 상태 확인
2. 홈 피드 상위 10개 게시물 메타데이터(작성자, 본문, 좋아요, 댓글 수) 수집
3. 참여도 상위 3개 게시물 필터링 후 인간화 말투 프롬프트로 맞춤형 소통 댓글 초안 생성
4. 사용자 승인(O/X) 후 게시 및 학습 DB(`agent_learning.feedback_logs`) 기록
