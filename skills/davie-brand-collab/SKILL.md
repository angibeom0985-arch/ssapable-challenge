# davie-brand-collab — 데이비 브랜드 협업 10단계 운영 스킬

## 1. 발송자 진위·사칭 검증 (Step 1)
- 발신자 도메인과 공식 브랜드 홈페이지 일치 여부 확인(무료 웹메일 사칭, 비정상 첨부파일·exe/zip 링크 차단).
- SPF/DKIM 통과 여부 및 실제 담당자 소속(LinkedIn/기업 홈페이지) 교차 확인.

## 2. 협업 유형 및 단가 산정 (Step 2~3)
- 요청 내용을 4가지 상품으로 매핑: 롱폼 단독 리뷰(150만 원), 롱폼 중간 PPL 90초(80만 원), 쇼츠·릴스 번들(70만 원), 2차 활용권 3개월(+100만 원).
- 기업이 2편 묶음 예산을 제시하면 1편 고품질 + 숏폼 파생 구조로 역제안해 제작 리소스를 방어한다.

## 3. 조건 합의·계약·선금 (Step 4~6)
- 필수 확인 조항: 수정 횟수(최대 1회), 2차 활용 범위·기간 분리, 경쟁사 배타 기간 제한, 지급 기한(선금 50% / 공개 후 7일 내 잔금 50%).
- 해외 브랜드는 PayPal Invoicing API v2로 USD 인보이스 발행, 국내 기업은 세금계산서 발행.

## 4. 시놉시스·제작·검수·공개·성과 보고 (Step 7~10)
- `brand/AGENTS.md` 말투 규칙을 적용해 1페이지 시놉시스 작성 및 사전 컨펌.
- 데이비 시그니처(얼굴 없는 PC 실전 시연, Before/After 수치 대조, `-14 LUFS` 마스터링)로 제작 후 유튜브 일부공개 1차 검수.
- UTM 파라미터가 포함된 고정 댓글 링크와 유료 광고 표시 적용 후 공개, 게시 7일 뒤 성과 리포트(조회수·클릭수·CTR) 전달 및 잔금 정산.
