# davie-brand-collab — 데이비 브랜드 협업 스킬

크리에이터 **데이비(`@david153.official`)**의 브랜드 광고·협찬 문의 접수부터 사칭 판별, 견적·역제안, 계약 검토, 시놉시스, 검수, 정산까지 10단계로 표준화한 AI 에이전트 스킬입니다.

## 실제로 AI에게 뭐라고 요청했고, 어떤 결과가 나왔나요? (실행 예시)

### 예시 1 — 해외 AI 툴 브랜드 협찬 메일 진위 확인 및 역제안 답장 작성
- **AI에게 한 요청**:
  > `davie-brand-collab` 스킬 기준으로 방금 들어온 해외 AI 영상 툴 협찬 메일(발신: `partnerships@ai-tool-example.com`, 제안 조건: 롱폼 2편 + 3개월 광고 2차 활용 총 $1,200)을 점검하고, 1편 단독 실전 시연 + 숏폼 1편 번들 조건으로 단가 협상 답장 초안을 영문/국문으로 써 줘.
- **실제 나온 결과**:
  1. **진위 판정**: 공식 도메인 일치 및 악성 첨부 없음(안전), 다만 2편 + 2차 활용 포함 $1,200은 편당 $600 미만으로 저단가 판정.
  2. **협상 전략 도출**: 상대 가용 예산이 $1,200 이상임을 근거로 **"롱폼 실전 시연 1편 + 쇼츠/릴스 1편 = $1,200 (2차 활용 3개월 별도 $600)"** 역제안안 자동 구성.
  3. **담당자 내부 결재용 회신 초안**: 채널 타깃(1인 창업가·콘텐츠 자동화 실무자), PC 화면 실전 데모 구성, UTM 전환 추적 방식이 담긴 영문/국문 메일 초안 즉시 생성.

### 예시 2 — 국내 SaaS 기업 협업 시놉시스 1페이지 자동 생성
- **AI에게 한 요청**:
  > `davie-brand-collab` 스킬과 `brand/AGENTS.md` 규칙을 적용해 국내 노코드 자동화 SaaS 브랜드의 6분 롱폼 시놉시스(0~30초 후킹, PC 실전 시연 2구간, 전환 CTA)를 작성해 줘.
- **실제 나온 결과**:
  - 과장 광고 문구 없이 "반복 작업 120분 → 12분 단축 실증" 중심의 5구간 타임라인 시놉시스와 썸네일 Before/After 카피 2안이 1분 이내에 완성되어 클라이언트 1차 컨펌용 문서로 바로 활용 가능.
