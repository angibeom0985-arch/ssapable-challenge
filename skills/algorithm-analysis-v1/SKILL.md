# algorithm-analysis-v1 — 시크릿모드 알고리즘 기반 영상 점수화·개선 스킬

## 1. 수집 기준 (시크릿모드 홈피드)
- 로그인·시청 기록이 없는 시크릿모드 유튜브 홈피드(한국 기준)에서 노출되는 영상 20편의 공통 패턴을 수집한다.
- 수집 항목: 제목 글자 수·숫자/대비 활용 여부, 썸네일 텍스트 어절 수(3~5어절 이내)·시선 대비, 영상 길이, 초반 15초 후킹 장치, 평균 컷 전환 간격.

## 2. 100점 평가 루브릭
| 평가 영역 | 배점 | 합격 기준 (85%+) |
| :--- | :---: | :--- |
| **클릭률 설계 (제목 + 썸네일)** | 30점 | 썸네일 텍스트 4어절 이하, 제목과 중복되지 않는 보완 카피, 구체적 숫자·Before/After 대비 포함 |
| **초반 30초 이탈 방어 (후킹)** | 25점 | 첫 5초 내 결과물/문제 즉시 제시, 15초 내 시청 보상(배울 것) 명시, 불필요한 인사말 제거 |
| **시청지속시간 구조 (대본 전개)** | 25점 | 60~90초마다 미니 클라이맥스·화면 전환 배치, 실제 PC 시연/숫자 근거 기반 전개 |
| **시청각 완성도 (음성·자막·리듬)** | 20점 | `-14 LUFS` 음량 정규화, 무음 0.25초 이하 압축, 1줄 20자 이내 자막, 발화 `+0.08s` 화면 싱크 |

## 3. 자동 개선 루프
1. 초안 영상의 대본·썸네일·타임라인을 입력받아 영역별 점수와 감점 원인을 출력한다.
2. 총점 85점 미만 또는 단일 영역 70% 미만일 경우, 수정 프롬프트와 구체적 개선안(제목 3안, 썸네일 재배치, 초반 30초 리라이팅)을 제시한다.
3. 개선 반영 후 재채점해 Before → After 점수 상승을 기록한다.
