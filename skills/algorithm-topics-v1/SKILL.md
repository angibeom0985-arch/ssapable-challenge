# algorithm-topics-v1 — 시크릿모드 홈피드 기반 유튜브 주제 발굴 스킬

## 1. 3단계 주제 발굴 프로토콜
1. **시크릿모드 홈피드 스캔**: 비로그인 홈피드 상위 노출 영상에서 공통 감정 트리거(시간 절약, 비용 절감, 손실 회피, 충격적 비교, 직접 검증/해부)를 추출한다.
2. **내 분야(콘텐츠 자동화) 교집합 매핑**: 데이비의 핵심 포지셔닝('해외·국내 터진 사례를 숫자로 해부하고 PC에서 직접 재현')과 대중 트리거를 결합해 후보 10개를 생성한다.
3. **5축 점수 필터링**: 검색 수요(20) + 홈피드 클릭 매력도(25) + 실전 시연 가능성(25) + 차별화(15) + 비즈니스 전환 연결성(15)으로 상위 5개 후보와 1순위 최종 주제를 선정한다.

## 2. 출력 형식
- 후보 5선 비교 표 (주제, 결합된 홈피드 트리거, 예상 타깃, 100점 예측 점수)
- 최종 선정 1개 주제의 제목 3안, 썸네일 문구 2안, 초반 30초 후킹 초안
